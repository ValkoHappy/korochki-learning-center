# Корочки.Есть

Учебный центр с каталогом курсов, регистрацией, личным кабинетом и заявками на обучение.

Учебный проект. Данные пользователей и заявки в репозиторий не включены.

## Возможности и устройство

PHP, MySQL, JavaScript и CSS. Авторизация и заявки обрабатываются отдельными контроллерами. Пользователь создаёт и удаляет свои заявки, администратор просматривает все заявки и меняет статус. В интерфейсе есть поиск и фильтры. Форма отзыва показывает уведомление и не сохраняет отзыв в базе.

## Запуск

Нужны PHP 8.2 или новее с расширениями `pdo_mysql`, `mbstring`, MySQL 8 и Python 3 для проверки HTTP-сценариев.

1. Создайте пустую базу MySQL с кодировкой `utf8mb4`.
2. Скопируйте `config/local.example.php` в `config/local.php` и укажите подключение. Вместо файла можно задать `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` в окружении.
3. Создайте таблицы в пустой базе.

```sh
php bin/setup.php
```

4. При необходимости создайте администратора. Задайте `ADMIN_EMAIL` и собственный `ADMIN_PASSWORD` в окружении, затем выполните команду.

```sh
php bin/create-admin.php
```

Пароль должен содержать от 12 до 72 символов. Для входа используется логин `administrator`. Готовых паролей в проекте нет. Уберите `ADMIN_PASSWORD` из окружения после создания аккаунта.

5. Запустите сервер.

```sh
php -S 127.0.0.1:8080 -t public
```

Откройте http://127.0.0.1:8080/. В OSPanel корнем сайта должна быть папка `public`, остальные каталоги не должны раздаваться веб-сервером.

## Структура

- `public/` — страницы и статические файлы.
- `src/` — подключение к базе, обработка запросов и сессии.
- `config/` — параметры подключения, локальный конфиг исключён из Git.
- `database/schema.sql` — таблицы без пользователей и заявок.
- `bin/` — установка схемы и создание администратора из командной строки.


## Проверка

На отдельной тестовой базе установите схему и создайте администратора. Тесты используют `TEST_ADMIN_EMAIL` и `TEST_ADMIN_PASSWORD`, создают синтетических пользователей и заявки. Не запускайте их на рабочей базе.

```sh
python tests/http_smoke.py http://127.0.0.1:8080
```

## Ограничения

Это учебная реализация, без отправки писем, реальных платежей и интеграций с внешними организациями. Для размещения в интернете нужны HTTPS, ограничение частоты входа, резервное копирование и настройки сервера. В проекте есть хеширование паролей, подготовленные SQL-запросы, проверка ролей и CSRF-токены. Приложение рассчитано на строковые поля стандартных форм.

GitHub Pages не выполняет PHP. Для запуска нужен сервер с PHP и MySQL.
